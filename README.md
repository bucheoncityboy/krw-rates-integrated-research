# 한국은행 통화정책 결정과 국고채 3s10s 금리곡선 반응

GAMMA 글로벌마켓학회에서 금통위 결정 전후 국고채 3년·10년 금리와 3s10s 스프레드의 움직임을 살펴본 발표자료입니다.

## 발표자료

- [최종 발표자료 (PPTX)](./KRW_Rates_Integrated_Research_Portfolio.pptx)

## 분석 내용

- 국고채 3년·10년 금리의 공통 관측일 1,084개와 금통위 정책결정 36회를 대상으로, 발표 전일 대비 다음 관측일(D+1)과 다섯째 관측일(D+5)의 변화를 비교했습니다.
- D+1 기준 3s10s 스프레드는 19회 확대(Steepening), 17회 축소(Flattening)됐습니다. 3년물의 절대 금리 변동폭이 10년물보다 큰 경우는 21회였습니다. 이 숫자는 **실제 커브 반응의 이벤트 스터디 결과**이며 거래 성과가 아닙니다.
- 완화 기대가 추가로 반영돼 3년물 금리가 10년물보다 더 크게 하락한다는 가정 아래, 3년물 매수·10년물 매도의 **DV01 중립 가상 포지션**을 구성했습니다. 양쪽 DV01은 가정 액면금액과 수정듀레이션을 사용해 각각 1bp당 280만 원으로 맞췄습니다.
- 발표자료의 손익 예시는 선택한 사례에 해당 가상 포지션을 적용한 민감도 계산입니다. 36회 전체에 적용한 전략 백테스트, 실제 체결 성과, 특정 KRX 국채선물 계약의 실측 DV01이 아닙니다.

## 해석 범위

인상·동결·인하 모두 스프레드 확대와 축소 양쪽에서 나타났습니다. 정책결정만으로 포지션 방향을 정할 수 없다는 것이 이 분석의 결론입니다. 선반영 가능성, 대외금리, 수급은 거래 전 확인할 항목으로 제시했으며, 각각의 영향이나 선반영 정도를 정량적으로 분해한 결과는 아닙니다.
